01 · LOGICAL ARCHITECTURE · CLIENT, BACKEND, DRM & DATA FLOW

1. 논리 시스템 & 금강(金剛) DRM 스트리밍 구성도 (Architecture)

클라이언트(마이정토 스토어·어드민 및 PDF.js 금강 DRM 뷰어), 코어 백엔드(주문·열람권·기기 3대 제어 서버 및 QPDF 사전암호화 빌더), 외부 금융·국세청 연동망, 그리고 데이터·엣지 전송 계층(CloudFront OAC + S3 Private + PostgreSQL/Redis)의 논리적 호출 구성도입니다.

CLIENT & GEUMGANG DRM

클라이언트 & 금강 DRM 뷰어

  • HTTP 206 청크 스트리밍: PDFDataRangeTransport로 64KB 조각만 수신하여 전체 PDF 원본 파일 다운로드를 원천 차단합니다.
  • 3페이지 가상 윈도잉: IntersectionObserver로 현재 페이지 ±1만 메모리에 유지해 아이패드·모바일 Safari OOM 크래시를 방지합니다.
  • 60fps 포렌식 워터마크: 성명·연락처·주문번호 가시 워터마크와 JTS-WM-SHA256 비가시 픽셀 해시를 동시 각인합니다.

CORE BACKEND & VBANK

백엔드 & 가상계좌 단일 파이프라인

  • 개인정보 최소 수집: 종이책 미발행으로 배송지 주소를 일체 수집하지 않으며, 미열람 환불 반환 계좌만 AES-256-GCM 암호화 저장합니다.
  • 웹훅 3중 무결성 검증: HMAC-SHA256 서명 + Redis SETNX 중복 차단 + 입금 금액 대조 후 즉시 열람권을 부여합니다.
  • E-ISBN 면세 자동화: 입금 즉시 국세청 부가세 0% 면세 현금영수증과 카카오 알림톡을 비동기 발행합니다.

EDGE & DATA VAULT

보안 엣지 & 원장 데이터 계층

  • CloudFront OAC + Signed URL: S3 버킷은 외부 접근을 완전 차단(Private)하고 TTL 300초 단기 서명 URL로만 청크를 전송합니다.
  • 무중단 개정판 배포: 오탈자 수정 시 /releases/v1.1.0/ 불변 경로에 배포하고 manifest.json 포인터만 원자적으로 전환합니다.

02 · PHYSICAL DEPLOYMENT · AWS AP-NORTHEAST-2 INFRASTRUCTURE TOPOLOGY

2. 물리 인프라 · 컨테이너 레플리카 · 아티팩트 배치 구성도 (Deployment)

실제 프로덕션 소프트웨어가 실행되는 네트워크 경계(ZONE 1: EDGE & CDN · ZONE 2: PROD VPC / EKS CLUSTER · ZONE 3: PRIVATE DATA SUBNET), 파드 레플리카 수(x2, x3), 배포 아티팩트 버전 태그, 그리고 포트·프로토콜 명세입니다.

03 · STATE MACHINE · VIRTUAL ACCOUNT & STATUTORY REFUND LIFECYCLE

3. 가상계좌 단일 결제 · 웹훅 멱등성 · 청약철회 상태머신 (State Machine)

신용카드 없이 오직 가상계좌(무통장 송금) 단일 수단으로 동작하는 주문·열람권 상태머신입니다. 입금 완료(PAID · GRANTED) 이후 독자가 단 1페이지라도 뷰어를 여는 즉시 READING_LOCKED 상태로 전이되어 온라인 자동 환불이 차단되며, 미열람(reading_started_at == null) 상태에서만 7일 이내 반환 계좌 이체 환불(REFUNDED)이 허용됩니다.

04 · DATABASE SCHEMA · COLUMN-LEVEL PHYSICAL DDL & FOREIGN KEYS

4. DATA 저장소 물리 DB 스키마 구성도 (Database Schema)

PostgreSQL 16 마스터 원장의 핵심 5개 물리 테이블과 실제 SQL 타입(varchar(32), bytea, timestamptz, jsonb), 제약 조건 칩(PK · FK · UQ · NN), 인덱스, 그리고 컬럼 대 컬럼(Column-to-Column)으로 연결된 외래키(`ON DELETE RESTRICT` / `ON DELETE CASCADE`) 명세입니다.
